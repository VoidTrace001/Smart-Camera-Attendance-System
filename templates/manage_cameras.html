Add a camera

Whatever staff call the room. It shows up on the control room.
  • 0 — the machine's built-in or first USB camera
  • 1 — a second USB camera on the same machine
  • rtsp://user:pass@10.0.0.40:554/stream1 — an IP camera
Leave both blank if the room is shared — the camera then follows whatever the timetable schedules there.
After adding

Start the worker for the new camera with the command shown on its card, or run python supervisor.py to start every active camera at once along with the attendance engine.
